# 工程规范

工程规范定义跨模块变更的最低要求：

- [Spec 编写规范](spec-writing-standard.md)：行为契约、失败恢复、并发、权限、迁移和验收矩阵。
- [测试规范](testing-standard.md)：单元、前端、真实基础设施集成和测试证据。
- [数据库迁移规范](database-migration-standard.md)：单一 Alembic head、真实 MySQL、数据保留和回滚边界。
- [前端契约规范](frontend-contract-standard.md)：跨层类型、i18n、Task room、错误恢复和用户流测试。

这些文档是开发约束，不是产品功能说明。产品行为以代码、架构文档和运维文档为准。
