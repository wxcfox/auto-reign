# 入门

按下面的路径开始使用 Auto Reign：

1. 本地开发：阅读[快速开始](quick-start.md)，运行 `./start.sh`。
2. 生产部署：阅读[生产部署与运维](../operations/production.md)，使用已发布的版本镜像。
3. 遇到问题：先看[故障排查](../operations/troubleshooting.md)，再检查对应服务日志。
4. 了解系统：阅读[概念导航](../concepts/README.md)和[平台架构](../architecture/platform.md)。

Auto Reign 不提供公开注册。空库首次启动后，需要通过 `/setup` 完成一次性管理员密码设置，再由管理员创建普通用户。
